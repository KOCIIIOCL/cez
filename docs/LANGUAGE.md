# Спецификация языка программирования Cez

Язык **Cez** — это системный язык программирования общего назначения с чистым и эргономичным синтаксисом **Go**, возможностями низкоуровневого контроля уровня **C/Zig** и гибкой гибридной моделью памяти (стек, арены, ручное управление и опциональный сборщик мусора).

---

## 1. Лексическая структура и синтаксис

### 1.1. Автоматическая расстановка точек с запятой (ASI)
Как и в Go, разработчик не пишет точки с запятой в конце строк. Лексер автоматически вставляет виртуальные разделители выражений после идентификаторов, литералов, ключевых слов `return`, `break`, `continue` и закрывающих скобок `)`, `]`, `}`.

### 1.2. Комментарии
```go
// Однострочный комментарий
/* Многострочный 
   комментарий */
```

### 1.3. Объявление переменных и констант
```go
// Явное типизированное объявление
var count int = 10
var active bool = true
var ratio f64 = 3.14159

// Краткая форма инициализации с выводом типа (walrus operator)
total := 100        // int
name := "Cez"       // *i8
speed := 99.5       // f64

// Глобальные и локальные константы
const MAX_BUFFER int = 4096
const VERSION *i8 = "1.0.0"
```

## 2. Система типов

### 2.1. Базовые числовые типы
| Тип | Размер | Описание | LLVM IR |
|---|---|---|---|
| `i8` / `u8` | 1 байт | Знаковый / беззнаковый 8-битный целое (байт) | `i8` |
| `i16` / `u16` | 2 байта | 16-битное целое | `i16` |
| `i32` / `u32` | 4 байта | 32-битное целое | `i32` |
| `i64` / `u64` | 8 байт | 64-битное целое | `i64` |
| `int` / `uint` | 8 байт | Машинное слово по умолчанию | `i64` |
| `uintptr` / `usize` | 8 байт | Беззнаковое целое размера указателя | `i64` |
| `bool` | 1 байт | Логический тип (`true` / `false`) | `i1` |
| `f32` | 4 байта | Вещественное число одинарной точности (IEEE 754) | `float` |
| `f64` | 8 байт | Вещественное число двойной точности (IEEE 754) | `double` |
| `void` | 0 байт | Пустой тип для функций без возвращаемого значения | `void` |

### 2.2. Указатели
Указатели поддерживают любую глубину вложенности:
```go
var x int = 42
var p *int = &x      // взятие адреса
var pp **int = &p    // двойной указатель
**pp = 100           // разыменование и запись
```

### 2.3. Массивы
Массивы имеют фиксированный размер времени компиляции:
```go
var buffer [256]u8
var numbers [10]int

numbers[0] = 10
val := numbers[0]
```

### 2.4. Структуры
```go
type Point struct {
    x int
    y int
}

// Инициализация структуры
p := Point{ x: 10, y: 20 }
px := p.x
```

### 2.5. Методы структур
Методы определяются с указателем-получателем (receiver):
```go
type Vector2 struct {
    x f64
    y f64
}

func (v *Vector2) LengthSquared() f64 {
    return v.x * v.x + v.y * v.y
}

func (v *Vector2) Scale(factor f64) {
    v.x *= factor
    v.y *= factor
}
```

## 3. Управление потоком выполнения

### 3.1. Условные конструкции `if` / `else`
```go
if score > 90 {
    puts("Grade A")
} else if score > 75 {
    puts("Grade B")
} else {
    puts("Grade C")
}
```

### 3.2. Циклы `for`
В Cez цикл `for` покрывает все виды итераций:
```go
// 1. Классический трехсекционный цикл
for i := 0; i < 10; i += 1 {
    // ...
}

// 2. Цикл с условием (while-стиль)
for active {
    // ...
}

// 3. Бесконечный цикл
for {
    if ShouldStop() {
        break
    }
}
```

### 3.3. Отложенное исполнение `defer`
Оператор `defer` регистрирует вызов функции или выражения, который гарантированно выполняется при выходе из текущей функции в порядке **LIFO** (Last-In, First-Out), даже при наличии нескольких операторов `return`:
```go
func ProcessFile(path *i8) int {
    fd := fopen(path, "r")
    if uintptr(fd) == 0 { return -1 }
    defer fclose(fd) // Гарантированно закроется при выходе

    // Обработка файла...
    return 0
}
```

## 4. Управление памятью

Cez предоставляет разработчику 4 уровня управления памятью:

1. **Стек (Zero overhead)**: локальные переменные, структуры и массивы аллоцируются на стеке.
2. **Арены памяти (`core/mem.cez`)**: быстрый bump-аллокатор `O(1)` без фрагментации. Идеален для OSDev, игровых циклов и парсеров компилятора:
   ```go
   var arena Arena
   arena.Init(buf, 65536)
   ptr := arena.Alloc(128)
   arena.Reset()
   ```
3. **Ручное управление (`malloc` / `free`)**: прямое выделение через libc или системный аллокатор ядра.
4. **Опциональный сборщик мусора (`core/gc.cez`)**: Mark-and-Sweep коллектор, включенный по умолчанию для прикладных утилит и отключаемый для ядра ОС.

## 5. Низкоуровневые возможности для OSDev

* `@packed` — убирает padding между полями структуры (аппаратные дескрипторы IDT/GDT).
* `@align(N)` — задает строгое выравнивание в памяти (например, 4096 для Page Tables).
* `@section("name")` — помещает переменную или функцию в заданную секцию ELF (`.multiboot`, `.text.boot`).
* `@naked` — отключает генерацию стандартного пролога/эпилога функции (для ISR и переключения задач).
* `inline_asm("...")` — прямой доступ к инструкциям CPU (`cli`, `sti`, `hlt`, `in`, `out`, `lidt`).
